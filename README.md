💬 SharowChat

SharowChat est un réseau social léger et minimaliste permettant de discuter, partager du contenu et découvrir d’autres utilisateurs depuis le Web.

🌐 Site : https://sharowchat.netlify.app

✨ Fonctionnalités

* 💬 Messagerie instantanée
* 📝 Messages texte
* 🖼️ Envoi d’images
* 🎙️ Messages vocaux
* 🎞️ GIFs
* 📢 Publications sur Xplore
* 👥 Ajout et gestion de contacts
* 👤 Consultation des utilisateurs
* 🔔 Système de notifications
* 🟢 Statut en ligne / hors ligne
* 🔐 Authentification
* 📱 Interface adaptée aux appareils mobiles
* 🖥️ Utilisable sur ordinateur
* 🌐 PWA installable

🚀 Objectif

SharowChat a été créé pour proposer une expérience de réseau social simple, rapide et accessible, sans fonctionnalités inutiles qui alourdissent l’application.

Le projet évolue progressivement avec l’ajout de nouvelles fonctionnalités et l’amélioration de l’expérience utilisateur.

🛠️ Technologies

SharowChat est principalement basé sur des technologies Web :

* HTML
* CSS
* JavaScript
* Firebase
* Netlify
* Progressive Web App (PWA)

📱 Installation

SharowChat peut être utilisé directement depuis un navigateur.

Sur les appareils compatibles, il peut également être installé comme une application PWA depuis le navigateur.

🔐 Sécurité

La sécurité du projet est améliorée progressivement.

Les données sensibles, clés privées et identifiants confidentiels ne doivent jamais être publiés dans ce dépôt.

Si vous découvrez une vulnérabilité de sécurité, évitez de publier les détails directement dans une issue publique.
